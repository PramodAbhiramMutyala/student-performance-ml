Academic Context & Model Advisory

This educational analytics system demonstrates early-warning predictive modeling on the UCI Student Performance dataset. The early-warning experiment strictly excludes intermediate grades (G1 and G2) so instructors can proactively identify at-risk students at the start of the academic term. Model predictions are probabilistic estimates and must never be used for punitive automated decisions.
